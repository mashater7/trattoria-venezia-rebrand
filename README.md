# Траттория Венеция: смысловой ребрендинг

Октябрь 2026. Для Аксиньи и владельцев сети «Траттория Венеция».

## Что это

Исследование и предложение по смысловому ребрендингу сети «Траттория Венеция». Меняем не логотип, а то, что ресторан обещает гостю, как о себе говорит и что показывает.

Слоган: **«Уголок Италии в Москве»**.

Идея: у каждого из трёх заведений свой характер, и мы называем его прямо.

- **Cantina** (Страстной): подвал, своды, камин, вино.
- **Cortile** (Столешников): двор за аркой, веранда, аперитив.
- **Forno** (Маяковская): дровяная печь, пицца, семейные праздники.

## Как открыть презентацию

- Локально: откройте `rebrand-site/index.html` в любом браузере. Фото встроены в файл, интернет не нужен.
- Онлайн: презентация опубликована как приватный артефакт claude.ai. Доступ к ней даёт автор через кнопку Share.

`rebrand-site/index.src.html` — исходник той же страницы. Он берёт фото из папки `rebrand-site/img/`.
