## 2. Структура сайта

Шаблон: WordPress 6.9, тема «editor» от Array (стандартная блоговая). Счётчик Яндекс.Метрики стоит.

- **Главная** `/`: один абзац про Венецию, список 4 точек с телефонами, ссылка «Напишите нам …обо всём, кроме бронирования».
- **Точки** `/trattoria-venezia/interior-01..04/`: описание, около 15–20 фото интерьера, как добраться, парковка, часы, оплата.
- **Адреса** `/where/`: 3 адреса, координаты текстом. Отдельной карты нет.
- **Меню** `/menu/`: оглавление из 14 разделов. Сверху плашка «20% скидка на всё меню с 11:00 до 16:00 по будням».
  - `m-01` Салаты (12), `m-02` Холодные закуски (7), `m-03` Горячие закуски (2), `m-11` Брускетты (2), `m-04` Супы (5),
    `m-05` Паста (15), `m-06` Лазанья (1), `m-07` Ризотто (5), `m-08` Рыба (7), `m-09` Мясо (12), `m-10` Гарниры (2),
    `m-12` Фокачча (6), `m-14` Пицца (10), `m-15` Десерты (14). Страницы `m-13` нет.
  - `/menu/drinks/`: чаи (13 по 490 ₽), кофе, лимонады, фреши, коктейли.
  - `/menu/bars/`: крепкий алкоголь с длинными справочными описаниями брендов.
  - `/menu/wines/`: вино, около 15 позиций (Италия, плюс Rioja и Pinot Noir).
- **Доставка** `/delivery/`: «доставляет наш партнёр Delivery-Club», 12:00–21:40, ссылка на delivery-club.ru.
- **Напишите нам** `/guest/`: стандартная форма комментариев WordPress (имя, email, сайт).
- **Мусор, открытый для индексации:**
  - `/stop-covid/`, `/stop-covid/b/`, `/stop-covid/w/`: копии меню, бара и вин 2020 года **со старыми ценами** (вино 180 ₽ против 450 ₽ сейчас; другие бренды).
  - `/menu/m-2021/`: «Масленица 2021», блины.
  - `/3019-2/`: страница без заголовка, черновик салатов со старыми ценами.
  - `/123444-2/`: тестовая страница «123444».

Меню двуязычное (RU + EN). В шапке написано «Меню / Menu / 菜单», но китайской версии нет.
Цены: салаты 590–1190, паста 590–1390, пицца 650–1190, мясо 690–1490, десерты 490–590, вино 3700–4700 за бутылку.
Средний чек, по оценке, около 2000–3000 ₽ на человека: демократичный сегмент для самого центра Москвы.

Сайт живой: меню обновлялось 04.05.2026, бар и вина 07.05.2026. Но рядом висят страницы 2020–2022 годов.

## Поправки после проверки агентами

- На страницах точек и на `/where/` встроены окна Google Maps (на точках есть ещё Street View 2016 года). Но они не кликаются: проложить маршрут или открыть приложение карт из них нельзя.
- `xmlrpc.php` уже закрыт (403). Зато через WP API виден логин администратора `admin`.
- Delivery Club превратился в «Маркет Деливери» от Яндекса, ресторана там нет (`not_found_place`). Ссылка доставки мёртвая.
- Плашка «Мы не продаём алкоголь лицам моложе 18 лет» на картах напитков есть.

## 3. Замеченное при обходе (сырой список для агентов)

Технические:
- нет HTTPS (https не отвечает), всё работает по http;
- ни на одной странице нет meta description и Open Graph;
- Schema.org (Restaurant, Menu, LocalBusiness) отсутствует;
- на каждой странице два H1: «Траттория Венеция» в шапке и заголовок страницы;
- все 14 разделов меню называются одинаково: title «Меню — Траттория Венеция», H1 «Меню». Пасту от пиццы по заголовку не отличить;
- URL без смысла: `m-05`, `interior-03`;
- у фото блюд нет alt (почти 100%), у интерьеров alt шаблонный;
- в подвале «Proudly powered by WordPress | Theme: editor by Array»;
- блок «Рубрики: Рубрик нет», поиск и прочие следы блогового шаблона;
- открыт xmlrpc.php, PHP 7.4 (больше не поддерживается);
- в sitemap попадают тестовые страницы и копии меню со старыми ценами.

Бизнесовые и смысловые:
- **нет онлайн-бронирования**, при этом форма прямо говорит «обо всём, кроме бронирования»;
- доставка ведёт на Delivery Club, который в 2023–2024 годах слился с Яндекс Едой и закрылся. Ссылка, скорее всего, мёртвая;
- главная страница — абзац общих слов про Венецию. Нет ни фото еды, ни конкретики, ни сценариев («обед со скидкой», «ужин вдвоём», «банкет»);
- у тратторий есть сильные отличия, но они спрятаны во внутренних страницах: камин, двор за аркой, чилаут на двоих, дровяная печь, веранды, дизайнер Вера Татаринова, 15+ лет работы;
- бизнес-ланч или скидка 20% с 11 до 16 — сильное предложение, но оно видно только внутри меню;
- кухня скорее «итало-европейская для всех», чем венецианская. Венецианских блюд почти нет (нет сарде ин саор, биголи, фритто мисто, чикетти, тирамису как гордости Венето). Есть бефстроганов, морковный торт, Цезарь, блины;
- нет отзывов, команды, шефа, истории, событий, соцсетей, подарочных сертификатов;
- нет карт (координаты даны текстом);
- тексты про алкоголь — справочные выдержки из Википедии про бренды, без голоса заведения.
